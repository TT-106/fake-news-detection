# CADE-FND 方法与可行性审计

审计日期：2026-10-22。对象：用户附件中的“反事实对比探针与去汇空间注意力双熵门控”方案。采用 academic-research-suite 的 deep-research / review 工作流，对已有方案做方法、文献、实现与实验设计审查。

**结论：值得做收缩后的机制预实验，现稿不宜直接作为已论证的开题蓝图。** 冻结 VLM 提取概率、注意力与隐状态并训练轻量分类器，技术上有实现路径；但“严格解耦无知与冲突”“无需外证精准识别时空移花接木”“残差保证性能下限”和“100 条样本显著即证明成立”均没有得到支持。其中部分可由明确数学反例否定。

按用户最新说明，**显存不是推进限制**。本报告不以 8GB、量化或运行速度作为方向取舍依据。资源数字仅作为原稿承诺的可复现性问题处理。

这是设计审计，不是实验结果。本轮没有下载数据集或模型、训练分类器、执行 VLM 推理，也没有产生任何检测性能。执行的 Python 仅核算构造反例和张量大小，见[计算核验](./计算核验.json)。原稿保持原样。

## 1. 哪些部分可以保留

方案有三处合理起点：把冻结大模型作为特征提取器以缩小训练范围；关注人物、地点、时间等局部声明以避免只测全局相似度；加入原图与干预图对照，以检验模型是否实际使用视觉输入。它们都能转化为可检验的设计。

但“存在可提取的内部信号”“该信号有预测增量”“该信号测到了新闻真值的生成机制”是三层不同的主张。前两层成功也不会自动证明第三层。

| 判断对象 | 当前判断 | 依据与边界 |
|---|---|---|
| 实现冻结 VLM 的离线探针 | 有明确实现路径 | 官方接口及既有预生成探针研究；本机接口尚未实测 |
| 用视觉干预诊断模型依赖 | 值得验证 | 可以比较同一预测位置的分布，但需排除遮挡伪影 |
| 用这些特征辅助错配分类 | 经验假设，尚无结果 | 应与 embedding、概率、注意力总量及隐状态探针比较 |
| 严格区分无知与冲突 | 原公式不成立 | 熵与 JS 存在支持/反对同值反例 |
| 仅凭内部信号普遍识别旧图新用 | 任务假设过强 | 某些时空事实不由当前可见输入唯一决定 |
| 以“双熵+门控+零生成”主张首次 | 目前证据不足 | SAE、VEGAS、HALP、HeadEntropy 等覆盖紧邻概念 |
| 以小样本箱线图保证论文成功 | 不成立 | 显著性不是机制证明、泛化证明或增量证明 |

## 2. 首先要修正任务：可见矛盾与外部事实不一致

**第一性原理推导。** 设输入为图片和文字 \(X=(I,T)\)，冻结模型及所有探针都是 \(f_\theta(X)\) 的函数。考虑两种可能世界：同一张无明显地标、无日期标识的洪水图片与“某地今天发生洪灾”的文字完全相同，但照片实际来源在一个世界与声明一致，在另一个世界来自旧事件。模型参数也相同。如果来源历史没有进入输入或模型已有知识，所有探针输出相同，却需要不同标签。

这说明：**这些信号不能无条件恢复输入中未被识别的拍摄日期、来源事件或人物身份。** 这不是说所有 OOC 样本都不可检测。地标、季节、文字标牌、知名人物，以及模型记忆的历史照片，都可能提供线索；数据集中的统计规律也可能有用。必须分别验证这些情形，不能用一类成功推出另一类。

建议把样本按“判定所需证据”另外分组，而不替换原始真假标签：

| 诊断组 | 示例 | 当前图文能否足以判断 |
|---|---|---|
| 可见支持 | 可见对象、数量、动作与声明相符 | 只能支持这些可见子声明，不能保证整篇新闻为真 |
| 可见矛盾 | 声明说三人，画面清楚显示一人 | 可作为视觉机制的阳性控制 |
| 视觉信息不足 | 无地标图片被标成新时间、新地点 | 应允许“不足以判断”；不能把无证据当成冲突 |
| 来源核验后确定的 OOC | 反向搜图或可靠历史出处证明旧图新用 | 可评价真实用途，需记录外部判定依据 |

在最后一组获得分类增益，也仍要排除来源风格、文字模板及预训练记忆的影响。NewsCLIPpings 的合成错配适合开发，真实 OOC 的外部有效性需要另验。[NewsCLIPpings 论文](https://arxiv.org/abs/2104.05893)

## 3. 词元熵和 JS：可以做探针，不能严格分解机制

### 3.1 原文的指标测量对象不同

应把完整词表分布明确写成

\[
p_i^I(v)=p_\theta(v\mid I,q,w_{<i}),\quad
H_i^I=-\sum_v p_i^I(v)\log p_i^I(v),\quad
D_i=\operatorname{JS}(p_i^I,p_i^{R}).
\]

其中 \(q\) 是固定提示，\(R\) 是具体视觉干预。\(H_i\) 测量下一词分布的不确定性，既受实体熟悉度影响，也受措辞、词频、分词、语法和前文影响。它没有直接检查实际出现的锚点是否被图片支持。

\(D_i\) 测量该分布对输入干预的敏感性。它可能源于合法证据损失，也可能源于黑块、模糊或全灰图造成的分布偏移。\(D_i\approx0\) 也可能表示图片本来不需要、干预没有遮到相关区域、模型未使用图片，或语言前缀已足以确定下一子词，不能直接归为“图文凑数”。

**构造反例，已用标准库计算核验：** 固定观测锚点为词表的第一项，掩码图分布均为 \((0.5,0.5)\)。原图分布分别为 \((0.9,0.1)\) 与 \((0.1,0.9)\)。前者提高该锚点概率，后者降低，但两者的 \(H\) 都为 0.325083 nats，JS 都为 0.101749 nats。仅用这两个数无法判断支持方向。它否定“严格解耦”的普遍保证，不否定某数据集上的统计相关性。

JS 永远非负。原文叙述的“负向冲突增益”并没有被 JS 公式定义；需要另设有符号量，例如

\[
\ell_i^I=\log p_i^I(w_i),\qquad e_i=\ell_i^I-\ell_i^R.
\]

这里 \(e_i>0\) 仅表示相较所选干预，原图提高了该实际锚点的条件似然；\(e_i<0\) 表示降低。它仍不是新闻真值，也不是充分的冲突证据。对多子词实体应记录跨度、逐词对数似然及聚合规则，控制实体长度与词频。

若人为定义二元变量 \(Z\) 表示“模型使用原图还是干预图”，等概率混合后 JS 可以解释为 \(I(Z;V_{\rm out})\)。这个互信息的对象是输入来源和模型输出，而非新闻真值与证据。不能据此把它称为已识别的“事实信息增益”。这是定义推导。

### 3.2 Teacher forcing 合法，但预测位置必须一致

同一因果序列中，输入真实新闻文字并评分下一词是合法的条件似然计算；不能笼统说 teacher forcing 本身泄漏标签。需要检查三点：

1. 若 \(w_i\) 位于序列位置 \(j\)，预测它的是位置 \(j-1\) 的 logits；位置 \(j\) 的隐状态已经看到它，通常预测下一词。与预测对齐的 attention query 也应明确选哪一行。
2. 若先把完整新闻放进 prompt，再要求模型重复或“补全”同一个锚点，模型已见锚点，得到的是带复制线索的概率，不能再解释成只给 \(w_{<i}\) 时的预测。
3. 新闻前缀评分、看到完整声明后的事实判断、生成答案后的幻觉检测，是不同测量协议。不能把它们的概率混在同一个机制解释里。真值标签、辟谣解释和核查结论均不得放入待测输入。

索引和因果 mask 的实现依据见[固定版本 Qwen2.5-VL 源码](https://github.com/huggingface/transformers/blob/v4.51.3/src/transformers/models/qwen2_5_vl/modeling_qwen2_5_vl.py)。

## 4. 去汇空间注意力熵：原式有数值问题，解释也过强

### 4.1 普通熵不记录关注位置是否正确

将同一组注意力值在图像位置间任意置换，香农熵不变。例如 \((0.7,0.1,0.1,0.1)\) 与 \((0.1,0.1,0.7,0.1)\) 的熵均为 0.940448 nats。一个头关注真正目标，一个头关注无关标识，纯熵可能完全相同。

这既是数学性质，也与 VEGAS §4.1、图2的讨论直接相关：作者用 block entropy 纳入局部聚集信息。分块熵仍不自动知道哪个区域与声明有关。SAE 则按语义分割类别聚合，讨论了对象面积和数量对原始 patch 熵的混淆。因此，原文把低熵直接解释为真实、高熵解释为造假，超出了指标含义。[VEGAS §4.1](https://arxiv.org/html/2512.12089v1#S4.SS1)；[SAE](https://arxiv.org/abs/2603.16558)

### 4.2 原式会把“无剩余信号”变成最低熵

若视觉部分 \(A=(0.05,0.05)\)，空图先验为 \((0.1,0.1)\)，则减法后 ReLU 得到全零。原式除以 \(0+\epsilon\) 后仍为全零，求和为零，**并非概率分布**，却计算出 \(H=0\)。系统可能把完全没有校准信号误解为最精确寻址。

应先定义 \(z_m=\max(0,A_m-B_m)\)，\(s=\sum_mz_m\)。当 \(s\le\tau\) 时记录缺失及残差质量，不输出“可靠低熵”；当 \(s>\tau\) 时再用 \(z/s\) 归一化。可以采用其他有明确定义的平滑分布，但必须报告规则并作敏感性分析，不能仅用 epsilon 掩盖问题。

同时保存原始视觉 attention mass

\[
M_i^{l,h}=\sum_{m\in V} A_{i,m}^{l,h},
\]

以及视觉部分归一化后的熵。向图像总共分配极少注意力时，局部归一化可以制造一个看似锐利的分布。还须固定“先跨头平均再算熵”或“各头算熵再平均”的顺序；二者不等价。对不同 patch 数可报告 \(H/\log M\)，但这只统一最大值，不消除语义和分辨率差异。

### 4.3 一张灰图的通用模板不能自动校准所有新闻

注意力依赖文本 query、长度、位置、图像 token 网格、层及头。通用模板下的空图分布不是任意实体位置的固有偏置。若输入分辨率不同，连视觉坐标和维度也可能不同。匹配分辨率仍不能保证匹配语义。

空图减法是一项待测启发式，不是已证实的 attention sink 消除器。可比较原始 attention、同文本同网格空图、训练集估计的基线及多种空图/纹理对照。若它仅改善 IID、换模板或填充即失效，就应撤回“消除模型固有黑洞”的机制主张。具体 shape 和后端限制见[工程核验附件](./工程可提取性核验.md)。

## 5. 门控与损失：两处需要实质修正

**冻结特征上的 margin 项不训练任何东西。** 原文先离线缓存 \(u\)，随后定义 \(\mathcal L_{\rm margin}(u_{real},u_{fake})\)。若这项没有可训练参数，对分类器参数 \(\phi\) 有 \(\nabla_\phi\mathcal L_{\rm margin}=0\)。把它加到 BCE 上只改变显示的损失数值。若要施加可训练约束，需作用于 \(h_\phi(u)\)、门值或预测表示，并说明为什么这一约束符合混合假新闻类型；不宜预先强迫所有假新闻“更高熵”。初期直接 BCE 更清楚。

**残差结构不能保证基线性能。** \(F_{sem}+g\odot\operatorname{Proj}(F_{cross})\) 可以容纳接近忽略附加分支的解，但不保证训练找到它，更不保证未见事件上不退化。若主干也更新，连原有基线函数都可能改变。可以冻结基线、将附加分支初始化为零、验证集选择融合强度并保留基线模型，但只能说“设计了回退与模型选择”，不能说锁死真实分布上的性能下限。这是优化与泛化边界的推导。

在门控之前先比较 \([F,u]\) 的线性分类器或同容量 MLP。如果收益完全来自新增参数或普通附加信息，门控不是必要机制。原文也没有由三项统计唯一推出 32 维特征，需明确每项、每层、每种锚点及池化维度。

## 7. 数据集不是可以互换的真假新闻容器

**NewsCLIPpings**：适合先验证图文错配与视觉依赖；应按原始图片、caption、来源文档和近重复关系分组，避免真配对在训练集、对应错配在测试集。抽取 1–2 万条是自定义子集，需记录抽样规则和官方 split，不能称其规模为固定“Balanced 官方子集”。CLIP 参与负样本构造，使用 CLIP 特征时还需按构造策略分层报告。[作者仓库](https://github.com/g-luo/news_clippings)

**Weibo21**：官方 MDFEND 实现面向多域假新闻，原始数据需申请，公开 dataloader 使用 content、label、category。本轮没有确认图像是否完整、图文是否可按原始 ID 配对，更没有确认假样本都是 OOC。不能据真/假数量直接承诺开展多模态实体矛盾实验。这也不等于证明申请版本没有图像。[官方仓库](https://github.com/kennqiang/MDFEND-Weibo21)

**VERITE**：可用于真实错配迁移检验，但有三类语义，需要按官方定义映射；不能把 miscaptioned 排除出所有时空错位讨论。当前访问和再分发条件须按数据卡落实，未取得数据不能写已完成真实性评估。[官方仓库](https://github.com/stevejpapad/image-text-verification)

**GossipCop**：新闻真假标签不直接等于配图是否支持某个锚点。若没有额外核验，就不适合验证“图文局部冲突”的机制主张。原方案用“或 GossipCop”替代 OOC 专门数据的论证不成立。

跨领域留一测试与新事件、时间泛化也不相同：8 域训 1 域测只直接检验领域迁移。要主张突发事件泛化，仍需按事件或时间分割并检查同事件、同图和近重复泄漏。预训练记忆不能仅靠下游随机分割排除。

## 8. 如何改成能回答问题的最小预实验

建议研究的收缩命题是：**在冻结模型和固定下游学习器条件下，锚点级视觉干预特征在控制常规图文表示、实体难度与图像复杂度后，能否改善未见事件的错配识别或错误风险预测？** 这是一项待作者选择的修改建议，本轮不替作者确认立题，也不启动实验。

原方案先叠加模块再期待每个组件带来正增益，难以定位失败。更可判读的顺序如下。

### 阶段 A：只验证测量是否正确

用约 10–20 个手工可核查样本，包含“明确可见对象”“明确矛盾”“像素无法判定的日期/地点”。人工核对锚点字符跨度到 tokenizer 子词的映射、图像 token 位置、因果 mask、logits shift、query 行、attention head 数和视觉网格。直接检查是否返回非空注意力。

保存原图、干预图、prompt、模型 revision、软件版本、数据 ID 和所有中间统计。原图重复计算作为数值噪声底线；禁用 dropout；单独记录无锚点、无视觉质量与校准残差全零。达到接口与数值正确即可通过本阶段，不要求显著性。

### 阶段 B：用配对设计观察是否存在增量

可以先准备约 200–300 个原始新闻/图像组作为探索量级，而非“保证充分”的样本量。能构造同 caption 下真实配图和错配图时，使用组内配对以控制词频与句式；同一组的所有变体只能进入同一个 split。实际独立单位仍是来源图片/文档/事件，不能把多个锚点、层、头或遮挡当成独立样本扩充样本量。

在运行前固定开发集、验证集与锁定测试集；开发集选择层、头、提示、符号、阈值和池化，测试集只做最终评价。需要数据较多的学习器可在开发部分交叉验证，小样本时保持模型简单，不能凭“测试箱线图漂亮”继续挑参数。真实 OOC 数据可作为后续独立迁移测试。

最低比较矩阵：

| 模型/特征 | 回答的问题 |
|---|---|
| 文本或图像单模态；固定图文 embedding + 相似度 | 是否只是单模态或匹配难度 |
| 上述特征 + 基础判别概率/熵 | 是否超出普通置信度 |
| 上述特征 + 锚点 NLL、词频、长度与锚点数 | 是否只是实体难预测 |
| 上述特征 + 原图/干预 JS 与有符号似然差 | 视觉干预是否有增量 |
| 上述特征 + VAR/视觉 attention mass | 熵是否仅替代了视觉注意力总量 |
| 原始熵、校准熵、分块或可复现的 SAE 变体 | 校准和空间结构是否必要 |
| 同样冻结模型的隐状态线性 probe（HALP 式） | 是否胜过廉价内部表示 |
| 简单拼接与同容量 MLP，对比残差门控 | 改善是否确实需要门控 |

HALP 式、SAE 变体移植到新闻任务时，必须披露为改编基线；只有按原论文协议实现才称完整复现。各项使用相同 split、标签、验证搜索预算与下游容量。

### 阶段 C：加入能推翻故事的对照

1. 相关区域遮挡对比等面积、尽量匹配位置/形状的随机遮挡；多个随机种子、至少两种填充；补充质量扰动以区分语义证据删除和图像退化。中心区域不天然等于声明相关区域。
2. 加入视觉上成立但文本时间/来源不成立的难负例，检验模型是否会低熵地错；同时加入真实但罕见实体、多个对象和大面积场景，检验高熵误报。
3. 保持注意力值集合不变而置换空间位置，展示纯熵的定位边界；它是数学控制，不是要求纯熵对这个操作变敏感。
4. 加入 probe 特征跨样本置换、无关锚点、同文本空图、多种灰图/纹理与难度匹配换图；检查提升是否来自样本长度、图像分辨率、锚点数量等代理特征。
5. 对去汇残差质量、视觉 attention mass 和缺失率分层；报告这些缺失是否集中在某标签或来源，防止分类器只学缺失模式。

可把 \(D_{相关}-\mathbb E[D_{随机}]\) 作为控制一般遮挡敏感性的候选诊断量，但仍不能叫真值因果效应。干预后若任务变得无法回答，不能机械要求模型继续输出原标签。

### 阶段 D：统计报告与继续/终止条件

主要看锁定测试集的增量 AUROC、Macro-F1，以及按任务选择的 Brier 或 log loss；检查类别 FPR 和“信息不足”组。阈值、方向与主要指标在开发阶段固定，用按来源/事件聚类的 bootstrap 给配对增量区间。模型随机种子的方差另外报告，不能把多个种子当新增新闻样本。没有可靠事件 ID 时，应披露聚类近似和残留泄漏风险。

**100 条 50/50 样本的 t 检验只能回答很窄的问题。** 即使预先固定一个统计量并满足检验条件，它也不能证明机制、跨事件泛化或相对基线的增量。若样本成对或同事件相关，独立样本 t 检验的单位还可能设错。ASA 明确指出 p 值不表示假设为真的概率，也不表示效应大小。[ASA 原始声明](https://doi.org/10.1080/00031305.2016.1154108)

量级核算：按两组独立、正态近似、双侧 alpha=0.05、power=0.80，每组 50 条约只能较有把握检出标准化差异 d≈0.56；聚类、多重检验和自适应挑选另需考虑。这不是对本实验的正式功效分析。若在 28 层、3 类指标间挑显著结果，即使全部原假设成立，在假想独立的 84 次检验下至少一次误报概率约 98.65%；真实指标有关联，此数不能当实际错误率，只说明选择自由度问题。[计算记录](./计算核验.json)

| 结果 | 合理决策 |
|---|---|
| 提取正确，对照后有稳定增量，未见事件仍有效，且胜过简单 probe | 扩大样本、第二模型与真实数据验证，再决定是否发展门控 |
| JS 有效、空间熵没有增量 | 保留视觉干预研究，撤去双熵必要性主张 |
| 只在可见矛盾有效，来源型 OOC 无效 | 收缩到可见一致性或风险探测，不宣称全面时空核查 |
| 等面积随机遮挡同样有效，或低成本质量特征解释全部收益 | 优先按伪影/难度代理处理，重新设计 |
| 隐状态 probe 或普通拼接效果相当且更简单 | 不以双熵门控作为主贡献 |
| 增量区间很宽、跨越零 | 证据不足；不能说成立，也不能说严格无效 |
| 区间上界已低于预先规定的最小有用增量 | 对当前任务和预算可停止该分支 |

最小有用增量应由研究目的和功效设计事先确定，不从原稿的 2.5%–3.8% 倒推。第一个周末最多定位明显实现/机制失败并估计效应量，不能保证给出最终可发表性判断。数据与环境若尚未准备，连两天内跑完接口也不应承诺。

## 9. 对原稿工程与性能数字的处置

原图、一个掩码图、一个匹配空图对应三份视觉条件，通常是每样本三次前向等价工作；若分前景/背景或逐锚点单独提问还会增加。合成一个 batch 不会把这些变为一份计算。“零生成”可以成立，“整套只需单次前向”不准确。

固定 Transformers v4.51.3 中，完整注意力在各层返回后收集，随后再切 14–18 层不能抹去已发生的峰值。不同后端是否返回权重也须检查。这是正确提取协议的问题；按用户说明，不作为本方向算力阻碍。

0.14 秒/样本、6.2GB、全量 20–30 分钟、15 倍加速，以及主表提升 2.5%–3.8%、每个模块提高 0.6%–1.8%，均没有本轮实测证据。应删除结果式承诺，改成记录每样本图像数、前向次数、分辨率、序列长度、吞吐与端到端耗时的评测计划。缓存后的训练速度不能代表含离线提取的总成本。完整细节见[工程核验](./工程可提取性核验.md)。

## 10. 审查收口与限制

**方法审查意见：大幅修改后做预实验。** 最值得保留的不是“双熵必然识假”的叙事，而是可证伪的增量问题：视觉干预和局部内部特征，在强简单基线之后还剩多少可迁移的信息。若确有增量，再解释何时有效、何时必须依赖外部证据。

**对抗性审查意见：原文最强机制主张应撤回。** 最强反对理由是：这套方法可能主要测量语言可预测性、图像复杂度和对扰动的敏感性，随后把与合成错配标签的相关性解释成新闻真实性机制。上文对照是为了给这个反对理由可被证伪的机会，而非预设方法无效。

**研究诚信与归因审查：有条件可用。** 原稿的预期增益和预期 p 值只能保留为明确的未测目标，不得作为已得到的结果或挑选图表的条件。纠正 ARG 会议信息、HeadEntropy 版本状态及 MMFakeBench 归因；数据申请和图像完整性仍待实际确认。本报告没有作机构伦理审批或数据使用授权判断。

本报告通过 Codex 辅助检索、阅读、推导与整理，包含同一 Codex 运行体系的有界分工；不是跨模型验证或专家评审。没有确认用户已阅读文献，没有完整复现任何所引论文。文献是否能迁移到新闻任务、数据实际可取程度、检测质量与最终论文价值均有待实测。检索仅支持截至本次所查来源的边界判断，不能证明穷尽文献或首次性。
