# 真实 Qwen 先导对照协议 v1

本协议在读取模型预测前锁定。用途是验证真实原图、冻结 7B 模型、本地 4bit 推理、逐样本记录与离线评分是否形成闭环；不是正式 E1—E4，也不是 FIRE/DEFAME/SAFE-MR 论文复现。

## 样本与隔离

使用 `config/pilot_split_20261117.json` 的完整 20 条训练集先导声明，共 24 张声明原图。样本来自修复前已经保存的 `outputs/method_repair/provisional_split.json` 的 `pilot` 用途，不根据当前模型得分、真假标签或难度重新选样。

训练 JSON、候选划分和先导清单均锁定 SHA-256。推理前与评分前分别检查版本，运行期间变动则拒绝发布成绩。事件分组仍未经过真实双人审核，保持 `human_event_review_complete=false`。官方 152 条开发评测声明不运行、不进入提示词，也不参与参数选择。

原图取自作者发布的 `Rui4416/AVerImaTeC` 归档，逐图校验 SHA-256 和实际解码。`PublicClaim` 仅包含 ID、事件组、原图、配文和事前时间地点；标签、核查文章、QA、解释、事后 metadata 不进入推理对象。预测文件关闭后才单独读取真值计分。

## 冻结模型与两种对照

模型使用官方 `Qwen/Qwen2.5-VL-7B-Instruct`，上游 revision 固定在 `models/Qwen2.5-VL-7B-Instruct/UPSTREAM_LOCK.json`；全部权重必须匹配上游 LFS SHA-256 后才能加载。采用本地 bitsandbytes 4bit，记录实际软件包、量化选项、提示词、处理器模板、图像像素上限和模型内容指纹。

两次运行共享四类标签、分类提示词、20 条样本、随机种子 42 和 200704 像素上限：

- `image_text`：模型真实读取声明原图和配文，无外部检索。
- `text_only`：通过已有 `InputView("no_image")` 实际移除图像，保留相同配文，无外部检索。

输入没有假证据、虚构来源关系或已训练充分性模型。每次分类直接取真实 forward 的 A/B/C/D 单 token logits 并 argmax；不把模型自报的概率作为校准概率。没有温度拟合、自动暂缓、证据充分性审核或有据正确回答指标；这些仍属于正式方法的待完成条件。

## 报告口径

主显示值为固定四类的 Macro-F1 与准确率；缺失类别的 F1 按 0 处理，不能为先导分布改变类别集合。另保留逐类支持数、逐样本预测、实际 logits、图像 SHA、请求日志、模型身份和原始推理耗时。

本地推理没有发生商业 API 账单，记录 `mean_cost_rmb=0` 只表示 API 实付为零，不代表硬件、电费、下载或人员成本为零。时延记录为逐样本耗时并另报模型加载在内的总耗时，不能与云端接口人民币费用混合解释。

这是一次先导测量，不报告多随机种子均值、统计显著性或“方法优于论文”的结论。图片对照与无图对照可以在相同先导组内展示；它们不能与二分类 FIRE、其他数据划分或正式 E4 工作点相减。

## 执行与复核

每次经 `tools/progress.py run` 包装，保存独立源码、环境、配置、划分、预测和 stdout/stderr。若加载、内存、数据版本或任一样本失败，本次记为失败，保留完整部分轨迹，不补分、不静默跳过样本。修复后的重跑使用新 ID 和新输出目录。

完成后由独立检查者重新计算指标、核对 20 个 ID、请求白名单与原图输入，再以 `reviewer-kind=agent` 记录机器核验。页面明确标为“先导·机器核验”，不计正式实验完成数。人工标注和人工事件复核仍在 `data/annotations/pending/review-20261117-01/` 等待真实审核者填写。
