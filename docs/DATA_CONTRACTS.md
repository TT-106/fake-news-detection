# 数据与模型接口

正式推理、离线监督与人工审核分开保存。文件存在不等于材料已经通过核验；执行器还会检查事件隔离、人工标注记录、快照哈希和引文位置。

## 数据用途

`experiment_split` 指向 JSON，包含 `dataset_sha256`、`event_groups`、`split`、`human_event_review_complete`。
`split` 有 `module_fit`、`temperature_calibration`、`pilot`、`action_train`、`mechanism_validation`、`final_eval`、`reserve` 七个列表。
ID 格式为 `train:索引` 或 `val:索引`。开发的 60 条再按事件分为拟合与温度校准用途，不能让同一事件跨两者。
最终评测必须完整保留官方 152 条；与其关联的训练样本单独隔离，不能放入任何训练或储备用途。

历史候选划分为 45/15/20/180/60/152/469，另隔离 4 条训练声明。当前锁定划分调整了储备和隔离数量，审核身份与用途见 [Sprint 2 事件协议](SPRINT2_AI_EVENT_PROTOCOL_20261122.md)。

## 人工监督

`source_annotations`、`quality_annotations`、`sufficiency_annotations` 分别是 JSONL，不能相互替代。
每行包括 `claim_id`、`event_group`、`features`、`label`、`evidence_proofs`。

`label` 包含两个不同人工审核者的 ID、各自的 `label_a`/`label_b`（0、1 或 null）和 `rationale`。
意见不同时必须有第三位 `adjudicator` 及 `adjudicated_label`；null 表示无法核实，不能被当作负例。
每行的 `evidence_proofs` 必须指向实际归档材料，而不是合成 URL 或最终报告。

| 模型 | 特征顺序 | 维数 |
| --- | --- | --- |
| 来源 LR | 引用链关系、时间接近度、已核实视觉出处匹配、文本近重复、同域名标记、时间已知标记 | 6 |
| 质量 LR | 出处可溯性、片段完整性、对当前原子声明的适用性 | 3 |
| 充分性 LR | 实际引文事实覆盖、核实图像出处、正通道均值、反通道均值、双通道共同强度、最大校准概率、引文可回放 | 7 |

训练文件只能包含模块拟合集标注。来源 Brier 评测需另备独立机制验证组的人工关系标注，不能复用训练标注当评测真值。

## 原图与网页快照

原图文件位于配置的 `image_dir`，加载时核对 SHA-256 并实际解码。
`ArchivedPassage` 保存证据 ID、HTTP(S) URL、UTF-8 快照文件路径与 SHA-256、正文位置 `start`/`end`、准确文本、含时区的取得时间。
字符位置针对完整 UTF-8 解码文本，结束位置不包含在内；不能把 HTML 清洗前的位置与清洗后文本混用。
图片出处已核实时还必须提供首发日期、作者及证明记录。图片主题相似、输入图片与声明图片相同，均不能代替历史出处核实。

规范事实的身份必须包括实体、事件、关系、极性及时间地点限定，不能只使用“时间”“地点”等槽位编号。
完全重复记录按规范 URL、快照哈希和片段位置剔除；不足 8 条时保留实际数量。

## 工具轨迹

`archived_tools` 指向真实请求归档 JSON，协议字段必须为 `OPEN_WEB_ARCHIVED_REPLAY`，包含工具和共享查询模板版本。
它按 `PublicClaim + ClaimAnalysis` 的指纹索引初始检索，按 `HistoryState.identity` 索引共享候选列表，按历史与具体行动的指纹索引实测返回。
精确记录缺失时立即失败，不从数据集 QA 中找答案补齐。

每条工具返回都需 `costs` 和 `outcome`。费用项包含请求 ID、组件、实付金额、耗时、成功/失败、请求摘要、计费依据和 token 用量。
失败请求也入账。零元须说明真实计费依据；本地推理记录耗时并明确没有 API 账单，不能杜撰人民币费用。
候选行动的预计成本和成本上限由先导样本核算，须覆盖该行动中的检索、材料处理、VLM 评分和状态更新。
最初处理费用和最终输出预留分别核算，不能只对搜索接口计费。

来源核验指向当前两个已获得片段，返回同源、独立或无法核实及实际证明。
它只能更新目标关系；不能因判为同源就额外把质量乘以 0.05，也不能恢复另一条隐藏答案。

## 模型与消融

`LocalQwenVLM` 只从已有本地目录加载 `Qwen2.5-VL-7B-Instruct` 或其明确量化版本。
它冻结权重、处理器文件哈希、提示词、图像像素上限和量化设置；不下载、不微调、不回退到 NLI。
终端 A/B/C/D 得分来自模型真实 forward 的单 token logits，经同一个独立校准温度归一化。
本地项目已有 NF4 真实图文工程运行记录。在新机器上按 [资源与环境说明](SETUP.md#单条-gpu-检查) 验证本机兼容性。

E2 保留同一个原始证据包、规范事实和来源结构：

- `no_image` 移除原图像素，保留共同检索包中的网页文字；这是该项消融的明确口径。
- `no_provenance` 从实际模型输入中去除 URL、作者、发布时间和出处证明字段，并在充分性 LR 实际入口将出处特征（第2维）置0。原始快照和来源矩阵仍保留用于回放；这个预注册范围由报告显式声明，不能称来源图也被消融。
- `no_spatiotemporal` 需要逐声明、逐原子文本、逐证据的时空文本遮罩及双人完整性复核；只关闭年份规则不合格。每张原图还须提供 `ImageMask(sha256,width,height,boxes)`，遮去图内的时空信号；经核查没有相关信号的图也须显式提交空框列表。遮罩只作用于模型可见副本，原图不变。人工复核仍须判断是否遗漏了隐含的视觉时空线索。
- `no_rules` 保持证据立场不变，仅移除可靠关系约束。没有可靠规则的样本原本就不添加通用规则。

遮罩采用 `TextMask(path,start,end,expected,evidence_id)`，先验证原文后替换；单片段和终端包通过证据 ID 对齐。
人工来源评测与遮罩缺失时，不生成相应 E1/E2 成绩。

## 实验边界

E3 的训练标签严格为 Chow 损失差，候选来自同一既有历史；采集深度必须预先确定为 1—3。
直接回归与完整回归共享相同记录，仅移除 χ；一般不确定性替换为目标对的 p(1-p)，匹配置换使用冻结训练组的同不确定性分层供体池，验证/在线不读取其他评测声明的特征。没有带目标来源对的训练样本时，该置换对照明确标记不适用。
基线路由只是公开的启发式对照，不是 FIRE、DEFAME 或 SAFE-MR 官方实现或论文复现。
E4 在机制验证上锁定竞争基线后才运行官方评测；`quality_cost_budgets` 可预先声明多个预算，曲线上的所有工作点沿用同一模型与基线锁定结果，不按评测结果重新选模型。真实工具归档缺少某一预算路径时停止，不模拟补全。
人工引文包仅导出盲审材料和空审核字段，不能把 URL 存在或自动评分代替双人充分性审计。


## 2026-11-17 修复后的新增归档约束

`fingerprint` 对dataclass、NumPy有限标量/数组和容器使用统一稳定规范化，原纯JSON哈希保持兼容；拒绝非有限数、循环结构和不支持类型。模型包递归冻结全部资源，包括根目录/嵌套的聊天模板和词表。

工具返回如声明 `resolved_gaps`，必须逐条提供 `gap_resolutions`：`{gap, evidence_id, quote, reason}`。引用的证据必须是本次实际取得并被状态接纳的新片段，quote必须与该片段准确对应。空返回、失败、旧证据或重复证据不能清除缺口；source_verify只更新目标来源关系，不解除事实缺口。结构校验不自动证明引文在语义上足以解决问题，仍需真实审核。

来源关系只接受布尔值或null三态，归档解析与状态更新分别校验。原始请求 `call_id` 保持不变，回放执行身份另记 `replay_execution_id`；整批账单先验证唯一性，再保留实际已发生费用，材料解析失败也不能漏账。

时空文本视图先统一tuple/list，现有字段的指定遮罩没有应用则拒绝，不适用情况写receipt。claim/atoms/gaps等全局字段遮罩不能绑定单条evidence_id，避免其它片段调用漏遮。

盲审包按字段白名单重建引文，方法相关路径和任意嵌套元数据只进独立私钥。公开包使用中性archive_id及SHA命名快照副本，审核者可脱离原方法目录核查正文位置；私钥不能分发给盲审者。

## 预核验逻辑规则目录

正式构造函数支持 `rule_manifest_path`，实验配置字段为 `rule_manifest`。目录协议是 `PREVERIFIED_SCOPED_RULES_V1`，监督范围为 `logical_relation_only`，每条关系绑定公开声明和原图输入SHA、明确实体/事件/时间/地点、两个原子文本、关系类型、正有限权重、真实归档证明及双人独立审核/必要仲裁。禁止从最终判定标签或QA生成目录。

`analyse` 将适用关系目录传入模型，模型只可选择已核验ID并精确匹配端点；程序据固定的蕴含/必要/不相容定义构造系数。未知ID、任意系数、版本错配或不适用端点均拒绝并留日志。没有可靠目录或适用规则时明确保存空规则，不伪造full/no_rules的区别。代码接通不表示真实规则材料已经齐备。

三类训练监督、来源独立评测、事件复核、时空遮罩和规则关系的人工审核均保持独立；机器核验先导运行不会代替这些人工语义标注。
