# 20 条真实取证先导的口径

数据来自 `config/pilot_split_20261117.json`。完整使用原定 20 条训练声明和 24 张原图。查询计划在第一次联网搜索前写入 `outputs/pilot/open-web-source-v1/query_plan.json`，包括初搜、来源追查和按声明日期设置的检索截止条件。查询词由代理根据公开配文编写。没有用数据集的核查文章、真值和标准问答生成查询或模型输入。

每条各做一次初搜和一次来源追查。每阶段最多抓取三个符合网址筛选规则且未尝试过的返回页面。搜索回执记录原样查询、解析出的标题和网址、实际调用耗时。每次网页抓取保存时间、HTTP 状态、重定向次数、最终网址或错误。成功抽取的文本按 UTF-8/LF 保存，片段用字符位置及 SHA-256 校验。HTML 页面缺可信发布日期、发布日期在声明当日或以后、抽取失败或正文不匹配时，不能拿该片段当时点证据。日期规则适用于页面的发布字段，片段仍需核查图文相关性。有一段无关的页面推荐内容在模型运行前排除，原抓取回执不覆盖。

来源追查采用公开网页的署名、引述、原发记录线索。明确的文字归因需指向实际片段。它可以说明报道援引了谁，或转载故事从哪里传来。原反馈不含反向图片搜索及原图匹配，所以本轮不登记已确认声明图源。不同域名不代表多个独立观察。找不到证据、无法确认来源和网页拒绝访问分别留下记录。

模型使用同一冻结 Qwen2.5-VL-7B-Instruct NF4 和全部原图，前后均以相同提示词从四个单 token logits 取最大项。初搜后只看初搜合格片段，追查后看同样的片段加新增合格片段和有依据的归因描述。追查查询均事先固定，不基于初判结果自适应。即使两次没有外部片段也执行两次真实前向，允许模型仍输出具体类别，因此「有类别预测」与「有网页支持」应分别检查。标签在两份预测关闭后才读取计分。

改判可以由新增内容或来源描述触发。这轮没有只替换来源信息的隔离对照，也没有训练 χ 决策，因此改判是描述性结果。逐条耗时是搜索工具、HTTP 抓取和模型前向分别计时再相加。网页抓取并行，累加值不等于墙钟时间。调用数按每次搜索、逻辑网页抓取和 Qwen 前向计数，网页重定向单独保留在回执。网页和搜索没有可核算账单时，不将其计为零元成本。

产物在 `outputs/pilot/open-web-source-v1/`。检索回执、网页结果、快照、40 次模型请求和前后预测保留在同一目录。看板显示逐条表，支持下载 CSV。此轮只验证真实取证覆盖、来源追查及前后判断的工程闭环，仍需要人工来源、质量和充分性标注，并在独立评测上跑同预算对照。
