每次实验保存独立记录、配置与产物哈希；重建页面即可更新，历史版本不覆盖。

依据本地申请书、当前源码及实验产物核查。未运行的实验保留为空；代码完成不等于研究结论成立。

持续更新这份档案

研究数据保存在项目文件中。页面筛选只改变视图，实验记录通过下列命令持久保存。

  1. 准备一版实验清单

    复制 progress/run.example.json，填写版本、数据集版本、划分、冻结模型、预算、随机种子及产物路径。每个种子和预算工作点使用独立 ID。

  2. 运行后自动登记 
    python tools/progress.py run --file progress/my-run.json -- python -m your_experiment

    包装器保存日志及退出状态；成功后从规范报告读取指标，失败同样存档。具体报告格式见更新文档。首次入库可标记待复核。

  3. 登记已有结果或更新页面 
    python tools/progress.py record --file progress/my-run.json
python tools/progress.py build

    已存在的 ID 不可覆盖。审核报告与逐样本证据后，用以下命令追加复核事件： 

    python tools/progress.py review --id 记录ID --reviewer 审核者 --note 复核说明

    先导机器运行核验须显式加 --reviewer-kind agent；正式实验仍需 human 具名人工复核。

    撤回使用 withdraw --id 记录ID --reason 原因，保留原件。

  4. 持续查看 
    python tools/progress.py serve --port 8765

    打开本机 http://127.0.0.1:8765，有档案变化时页面自动更新。也可直接双击根目录的 研究进度.html 查看离线快照。

进入曲线的条件：完成、对应阶段核验、证据齐全、文件校验通过。先导可由机器核对运行日志、逐样本预测与指标重算，标记“先导·机器核验”；正式实验须具名人工复核。机器运行检查不替代双人科学标注、事件审核或人工引文审计。比较组同时锁定阶段、数据、划分、协议、模型、预算与样本量；不同条件不直接比较。种子记录逐点展示，不冒充均值或置信区间。基线运行通过核验不自动等于忠实复现论文方法。
